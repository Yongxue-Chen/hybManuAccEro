# ==================================
# 项目部署清单 (windeployqt 方法)
# ==================================

# 准备工作
# ----------------------------------
# 1. 确保代码编译无误。
# 2. 在 Visual Studio 中，将配置从 "Debug" 切换到 "Release"。
# 3. 右键点击项目，选择 "重新生成(Rebuild)"。

# 步骤一：创建发布文件夹
# ----------------------------------
# 1. 在项目根目录创建一个名为 "Deploy" 或 "Release_Package" 的文件夹。
# 2. 进入项目的生成目录 (例如 `x64\Release`)。
# 3. 复制生成的 `.exe` 文件 (例如 `myprogram.exe`) 到 "Deploy" 文件夹中。

# 步骤二：运行 Qt 部署工具
# ----------------------------------
# 1. 从 Windows 开始菜单，搜索并打开与项目匹配的 Qt 命令行工具。
#    (例如: "Qt 5.14.2 (MSVC 2017 64-bit)")
#
# 2. 在打开的命令行窗口中，使用 `cd` 命令进入刚才创建的 "Deploy" 文件夹。
#    示例: cd C:\path\to\your\project\Deploy
#
# 3. 运行 windeployqt 命令:
#    windeployqt your_program_name.exe

# 步骤三：检查和收尾
# ----------------------------------
# 1. 确认 "Deploy" 文件夹中已经自动添加了很多 dll 文件和子文件夹。
# 2. (可选) 如果你的程序用到了图标、配置文件、图片等，手动将这些文件也复制到 "Deploy" 文件夹中。
# 3. 将整个 "Deploy" 文件夹压缩成 zip 包，即可分发。

# 注意事项
# ----------------------------------
# - 目标电脑可能需要安装 Visual C++ 运行时库 (VC++ Redistributable)。
# - 每次更新程序后，都需要重新执行一遍此流程。
